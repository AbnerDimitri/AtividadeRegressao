# AtividadeRegressao
# Regressão Linear com Scikit-learn

Este repositório contém dois exercícios práticos de regressão linear simples utilizando Python, `pandas`, `scikit-learn` e `matplotlib`.

---

## 📁 Estrutura

.
├── exercicio1_altura_peso.py
├── exercicio2_aditivo_octanagem.py
└── README.md

## 📌 Requisitos

Antes de rodar os scripts, instale as dependências:

pip install pandas scikit-learn matplotlib

Exercício 1: Prevendo o Peso pela Altura
Cria um dataset fictício com altura (cm) e peso (kg).

Treina um modelo de regressão linear.

Exibe a equação da reta e o R².

Estima o peso de uma pessoa com 170 cm de altura.

Gera um gráfico da regressão.

Rodar:
python exercicio1_altura_peso.py

Exercício 2: Prevendo a Octanagem pelo Percentual de Aditivo

Utiliza um conjunto de dados com diferentes percentuais de aditivo e suas respectivas octanagens.

Treina um modelo de regressão linear.

Exibe a equação da reta e o R².

Estima a octanagem para 5,5% de aditivo.


Gera um gráfico da regressão.

Rodar:
python exercicio2_aditivo_octanagem.py
